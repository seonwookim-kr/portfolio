# 김선우 | 업무시스템 구축 PM / PL

현업 요구를 운영 가능한 시스템 요건으로 바꾸고, 개발·벤더·고객을 조율해 결과로 만드는 일을 합니다.
ERP와 그룹웨어 구축, 두 시스템 사이의 마스터 데이터 연동이 주 영역입니다.

## 대표 프로젝트

### 전사 ERP 통합 그룹웨어 구축 — 통신 서비스업
`2025 - 2026` · 역할 PL (그룹웨어 모듈)

ERP 전 모듈과 그룹웨어가 묶인 전사 통합 시스템에서 그룹웨어 모듈을 맡았습니다.
메일, 전자결재, 포털, 조직도 전 영역의 구현안을 현업과 협의해 확정했고, ERP와는 조직도·사원 데이터를 연동해 계정이 자동 생성되도록 구성했습니다. 나머지 그룹웨어 영역은 연동된 조직·사원 데이터를 받아 동작합니다.
오픈 후 조직도가 넘어오지 않는 API 호출 문제는 쿼리로 데이터를 확인해 해결했습니다. 현재 운영 중입니다.

### 조직도·계정 연동 구축 — 식음료 프랜차이즈 (약 100명, 법인 2개)
`2024` · 역할 PM · **부서 내 첫 사례**

표준은 ERP에 조직도를 먼저 만들고 그룹웨어가 따라가는 순서입니다.
이 고객사는 그룹웨어를 먼저 열기를 원해 ERP가 후행이 됐고, 따를 절차가 없었습니다. 기존 방식대로라면 조직도를 두 곳에서 따로 관리해야 했습니다.

- 그룹웨어 조직도를 기준으로 ERP 조직도를 구성하는 방식을 제안
- 테이블 구조가 달라 직접 연동이 안 되는 부분은 설계 담당자와 협의해 별도 매핑 테이블로 해결 가능함을 확인
- 구현은 개발에 요청하고 일정과 확인 사항을 조율 (매핑 설계·개발은 개발 담당)

지금은 조직도를 ERP 한 곳에서만 관리하고, 배치가 API로 그룹웨어 계정에 반영합니다.

### ERP 연계 그룹웨어 구축 — 제조업
`2025 - 2026` · 역할 그룹웨어 PM · 2개월 단기 오픈

수년치 ERP 데이터를 이관하는 환경에서 2개월 일정으로 그룹웨어를 열었습니다.
오픈 이후, 연동 이력 테이블 한 곳에서 미완료 이력이 누적돼 신규 사원 4명의 계정이 만들어지지 않는 것을 발견했습니다. 생성형 AI를 함께 써서 쿼리로 미완료 이력을 직접 확인한 결과, 사원 한 명의 중복 키 오류에서 배치가 매번 멈추고 그 뒤 이력이 전부 막혀 있었습니다.
연동 비대상 이력은 가려서 처리하고 확인 내용을 정리해 개발팀에 전달했습니다. 미완료 이력 0건, 신규 사원 4명 정상 등록으로 마무리됐습니다.

### 그룹웨어 구축 — 고객서비스업
`2026 - 진행 중`

- 템플릿 없이 쓰이던 전자결재 양식을 전사 전수조사해 표준 템플릿으로 제작
- 파일로 관리하던 양식을 웹오피스로 옮겨 사내 자산화
- 게시판으로 공유하던 자료를 파일 중앙화 방식으로 전환 제안
- 외부 유출 방지를 위한 웹오피스 PDF 다운로드 제어 개선

부서원들이 야근을 덜 하도록 직접 만들어 배포했습니다. 배포 전에 제가 먼저 써 보며 확인했고, 가이드와 FAQ는 IT 비담당자도 바로 쓸 수 있게 썼습니다.

| 도구 | 하는 일 |
|---|---|
| 전자결재 양식 제작 방법론 | 생성형 AI로 HTML 결재 양식을 만드는 방식. **부서 최초 정립**, 5개 고객사 적용 |
| 포털 구성 설계 도구 | 조건을 입력하면 포틀릿 35종 기준으로 포털 구성안을 자동 도출 |
| 방화벽 요청서 생성기 | 고객사 정보를 넣으면 요청서를 Excel/PDF로 자동 생성 |
| 조직도·코드 변환 도구 | 레거시 코드와 표준 코드를 엑셀에서 하나씩 대조해 옮기던 수작업을 자동화 |
| 연동 점검 표준 쿼리 세트 | 조직도 연동 상태를 정해진 순서로 점검 |
| 사내 FAQ 자동응답 | 반복 문의에 자동으로 답하도록 구성·배포 |

## 표준을 만든 일

- 그룹웨어 전용 구축 공수(M/M) 산정 기준 정립 — 새 제품 사업이 부서로 이관되며 기준이 없던 상황
- 원격지원 구축 커리큘럼, 교육 점검 체크리스트 제작 — 새 구축 방법론 과제 중 해당 영역 담당
- 표준 구축 일정표, 온보딩 자료 정비
- 제품 개선 기여 — 고객 요청 수집 및 베타 검증
